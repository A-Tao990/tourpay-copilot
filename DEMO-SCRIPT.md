# 3-minute demo script
1. (0:00) Problem: VND pricing vs PayPal; tourist + shopkeeper with no shared language. Show the header badges (PayPal sandbox, AI brain).
2. (0:25) Chinese tourist: `账单 450,000 越南盾,用美元付` -> amount, live rate, PayPal link in Chinese.
3. (1:00) English: `3 x 45k + 80k, pay in USD` -> sums to 215,000 VND = ~8.33 USD. Open the link, approve on PayPal sandbox.
4. (1:40) `status` -> `confirm payment` -> COMPLETED; show the receipt and the Orders table.
4b. (2:00) Merchant dashboard: today's totals by currency, CSV download; then `refund` -> refund issued, dashboard updates.
5. (2:10) Vietnamese: `tổng 1,2 triệu, thanh toán bằng EUR`; then `how can I pay in Vietnam?` -> honest options, including that crypto is not legal tender for payments.
6. (2:40) Design principle: the model never touches money; tests; what is verified vs not; next steps.
